## 1. 快速开始

### 启动服务

**方式一：一键启动（推荐）**

双击项目根目录的 `打开博客.bat`，会自动启动服务并打开浏览器。

**方式二：命令行启动**

```bash
cd qrcode-login
npm install   # 首次运行需要安装依赖
npm start
```

启动后访问：
- 本机：http://127.0.0.1:3000
- 局域网：http://<你的电脑IP>:3000（手机和电脑在同一 Wi-Fi 下可用）

### 内置管理员账号

- 账号：`admin`
- 密码：`123456`

> 首次启动时自动创建。建议登录后修改密码（如果已启用用户设置功能）。

## 2. 登录与注册

### 方式一：账号密码登录（电脑端）

1. 打开登录页
2. 在二维码下方找到「账号密码登录」区域
3. 输入账号和密码
4. 点击「登录」按钮

### 方式二：手机扫码登录

1. 电脑端打开登录页，显示二维码
2. 用手机浏览器扫描二维码（手机和电脑需在同一 Wi-Fi）
3. 手机端跳转到确认页面
4. 在手机端输入账号密码（或注册新账号）
5. 点击「确认登录」
6. 电脑端自动进入项目中心

### 注册新账号

1. 扫码后在手机端确认页面点击「注册」
2. 输入用户名（2-20 位，支持字母、数字、中文、@._-）
3. 输入密码（6-32 位）
4. 点击「注册」
5. 注册成功后返回登录

## 4. 导入自定义项目

你可以将自己的网页项目导入到项目中心，像应用图标一样展示。

### 准备工作

1. 将项目文件夹放到 `blog/projects/` 目录下
2. 在项目文件夹根目录创建 `project.json` 文件

### project.json 格式

```json
{
  "name": "我的项目",
  "entry": "index.html",
  "version": "1.0.0",
  "description": "项目描述文字",
  "icon": "🎮",
  "color": "c1",
  "author": "你的名字",
  "tags": ["标签1", "标签2"]
}
```

**必填字段**：
- `name`：项目名称
- `entry`：入口文件名（如 `index.html`），文件必须存在

**可选字段**：
- `version`：版本号（字符串）
- `description`：项目描述
- `icon`：单个 emoji 或字符，默认 📁
- `color`：卡片颜色，可选 `c1` ~ `c6`，默认 `c1`
- `author`：作者
- `tags`：标签数组

### 导入步骤

1. 进入项目中心
2. 点击右上角的「+」按钮
3. 在弹出的列表中找到你的项目文件夹
4. 系统会自动验证 `project.json` 规范
   - ✅ 符合规范：显示项目名称和图标，可点击导入
   - ❌ 不符合：显示错误原因（如缺少 name、入口文件不存在）
5. 点击「导入」按钮
6. 项目卡片出现在项目中心

### 删除导入的项目

1. 在项目中心找到要删除的项目卡片
2. 点击卡片上的删除按钮（内置项目不可删除）
3. 确认删除

> 删除只是从项目中心移除，不会删除 `blog/projects/` 下的源文件。

## 5. ChatRecord 会话时序实验室

把聊天记录变成可计算的数字表征，生成 8 种可视化图表。

### 创建会话

1. 从项目中心进入 ChatRecord
2. 点击「新建会话」
3. 输入会话名称（可选）
4. 开始导入聊天记录

### 导入聊天记录

**方式一：文本粘贴**
1. 切换到「文本导入」标签
2. 粘贴聊天记录文本
3. 点击「解析」

**方式二：JSON 导入**
1. 切换到「JSON 导入」标签
2. 粘贴 JSON 数组格式的消息
3. 点击「导入」

**方式三：截图 OCR 识别**
1. 切换到「截图识别」标签
2. 上传微信/QQ 聊天截图
3. 系统自动 OCR 识别并解析
4. 识别结果可编辑后导入

> OCR 优先使用本地 RapidOCR 服务（识别率高），未启动时自动回退浏览器端 Tesseract.js。

### 可视化图表

导入后自动生成以下图表：

| 图表 | 说明 |
|------|------|
| 时序波形 | 消息量随时间变化的波形图 |
| 消息量分布 | 按天/小时统计消息数量 |
| 平均长度 | 消息平均长度变化趋势 |
| 日历热力图 | 按日期展示消息活跃度 |
| 发送者统计 | 各发送者的消息量占比 |
| 复读指数 | 重复消息的频率分析 |
| 周×小时热力图 | 一周内各时段的活跃度矩阵 |

### 多会话管理

- 左侧边栏显示所有会话
- 点击切换会话
- 自动保存（输入后 1.5 秒防抖保存）
- 可重命名、删除会话

### 分享会话

1. 打开要分享的会话
2. 点击「分享」按钮
3. 生成分享链接
4. 将链接发给对方
5. 对方无需登录即可查看图表（只读）

> 分享链接在服务重启后失效。

## 6. 常见问题

### Q: 忘记密码怎么办？

A: 目前没有密码找回功能。如果是管理员账号，可以修改 MySQL 数据库中的 `users` 表，或删除该用户后重启服务（会自动重新创建内置管理员）。

### Q: 手机扫码后打不开页面？

A: 检查以下几点：
1. 手机和电脑是否连接同一个 Wi-Fi
2. 电脑防火墙是否放行 3000 端口
3. 二维码中的 IP 地址是否正确（可以在浏览器手动输入 `http://<电脑IP>:3000/mobile-confirm.html?qid=xxx` 测试）

### Q: OCR 识别不准确？

A: 
1. 确保安装了 Python 依赖：`pip install rapidocr_onnxruntime pillow numpy`
2. 确保 OCR 服务在运行（端口 8765）
3. 截图尽量清晰，避免反光和模糊
4. 可以在识别结果页面手动修正

### Q: 数据存在哪里？

A:
- 用户账号：MySQL 数据库 `myself_blog2` 的 `users` 表
- ChatRecord 会话：`qrcode-login/data/chatrecord/{用户名}/` 目录
- 导入的项目列表：`qrcode-login/projects.json`

### Q: 如何备份数据？

A:
```bash
# 备份数据库
mysqldump -u root -p myself_blog2 > backup.sql

# 备份 ChatRecord 数据
# 复制 qrcode-login/data/ 目录
```

### Q: 服务启动失败，提示 MySQL 连接错误？

A:
1. 确认 MySQL 服务已启动
2. 检查 `qrcode-login/.env` 中的数据库配置（用户名、密码、端口）
3. 确认数据库用户有创建数据库的权限

### Q: 如何修改端口？

A: 编辑 `qrcode-login/.env`，修改 `PORT=3000` 为你想要的端口，然后重启服务。
