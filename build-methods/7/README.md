# 7. PWA 渐进式 Web 应用

## 特点
- 纯 Web 技术，但可以像 App 一样安装到桌面/手机主屏幕
- Service Worker 实现离线缓存，断网也能打开
- manifest.json 定义应用名称、图标、全屏模式
- 数据存在 localStorage

## 运行
```bash
node server.js
```
打开 http://localhost:3007

## 体验 PWA 特性
1. **安装到桌面**：Chrome 地址栏右侧会出现安装图标，或点页面上的「安装到桌面」按钮
2. **离线可用**：打开后断网刷新，页面依然能正常使用
3. **全屏体验**：安装后从桌面打开，没有浏览器地址栏，像原生 App

## 感受
- 优点：不用下载安装包，Web 技术就能做 App 体验，跨平台，离线可用
- 缺点：iOS 支持不如 Android，部分原生功能受限，性能略逊于原生
