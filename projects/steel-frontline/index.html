游戏简介

钢铁前线·狙击是一款基于 Electron + Three.js 打造的纯前端 3D 二战写实射击游戏。无需后端服务，所有渲染和逻辑都在本地完成。

游戏采用占点 + 兵力制（Ticket）模式，进攻方需要占领全部据点或耗尽防守方兵力才能获胜，防守方则需守住据点直到进攻方兵力耗尽。

核心特性

🔫

20+ 真实二战武器

Kar98k、M1 加兰德、MG42、MP40、莫辛纳甘、春田狙击步枪等，每种武器独立参数和音效。

🗺️

10 大战役

诺曼底登陆、斯大林格勒、柏林、突出部、百团大战、莫斯科、冲绳等经典战役地图。

⚔️

6 大阵营

美军、苏军、德军、日军、国军、八路军，各阵营有独立武器池和语音。

🤖

AI 智能士兵

状态机驱动的 AI：巡逻、交战、包抄、找掩体、推进，120° 视野锥，真实射击节奏。

🚗

可驾驶坦克

玩家可驾驶坦克，独立 AI 炮手自动瞄准射击，坦克有独立血量和移动物理。

🔊

3D 空间音效

Web Audio API 实现 3D 空间音效，每种武器独立 MP3 音效，支持音量调节。

武器列表

Kar98k M1 加兰德 MG42 MP40 莫辛纳甘 春田狙击枪 SVT-40 M1911 鲁格 P08 TT-33 BAR DP-28 FG42 波波沙 三八式 MK2 手雷 RGD-33 M24 木柄雷 铁拳

操作方式

WASD 移动 · Shift 冲刺 · Ctrl 切换行走/奔跑 · C 蹲下 · Z 卧倒 · Q/E 探头 · 空格 跳跃

鼠标左键 开火 · 鼠标右键 瞄准（ADS）· R 换弹 · F 互动/上下坦克 · T 驾驶坦克 · 1/2/3 切换武器 · V 小队指令 · G 手雷

⚠️ 运行说明

本游戏基于 Electron + Three.js 开发，使用 ES Modules，需要 Node.js 环境和 npm install 安装依赖（Three.js）后才能运行。音频文件（MP3）需要自行准备放入 audio/ 目录。

推荐从 GitHub 克隆后运行 npm install 再执行 play.bat 启动游戏。
